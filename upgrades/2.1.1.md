# 2.1.1

Action required: no

Fixes two examples that could not work as written. Nothing else changed. A
project that copied either example has the same fault and can apply the fix
below; a project that did not is unaffected.

## 1. Toasts triggered from the server never appeared

`core/htmx.md` sent an `HX-Trigger` named `showToast`, but the toast partial in
the same chapter listens for `toast` and reads `level`, not `type`.
`core/frontend.md` was already correct.

- **Find:** `showToast` in controllers.
- **Change:** rename the trigger to `toast`, and its `type` key to `level`.
- **Check:** an action that sets the header shows a toast.

## 2. Record audit name helpers raised AttributeError

`created_by_name` and `updated_by_name` in `core/audit.md` read `first_name` and
`last_name`. The blueprint's `User` has a single `name`.

- **Find:** `first_name` in the project's `AuditMixin`, on a project whose
  `User` has no such field.
- **Change:** return `self.created_by.name` and `self.updated_by.name`.
- **Check:** a template that prints `item.created_by_name` renders.

A project whose `User` really has `first_name` and `last_name` changes nothing.
