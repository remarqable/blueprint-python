# Internationalization (i18n) Patterns

> Complete guide to translations in Blueprint Go.

---

## Overview

Blueprint uses **module-scoped JSON translation files**:

- Each module has its own `views/lang/` directory
- JSON files named by language code (e.g., `en.json`, `es.json`)
- Fallback chain: module → core → original text
- Template function `T` for translations

---

## Directory Structure

```
modules/yourmodule/
└── views/
    └── lang/
        ├── en.json
        ├── es.json
        └── fr.json
```

## Translation System

### Loading Translations

```go
// internal/system/i18n/translation.go

var translations = make(map[string]map[string]map[string]string)
// Structure: lang -> module -> key -> value

// Load reads all translation files from modules
func Load(modulesPath string) error {
    entries, _ := os.ReadDir(modulesPath)

    for _, entry := range entries {
        if !entry.IsDir() {
            continue
        }

        moduleName := entry.Name()
        langPath := filepath.Join(modulesPath, moduleName, "views", "lang")

        langFiles, err := os.ReadDir(langPath)
        if err != nil {
            continue // Module might not have translations
        }

        for _, langFile := range langFiles {
            if filepath.Ext(langFile.Name()) != ".json" {
                continue
            }

            langCode := strings.TrimSuffix(langFile.Name(), ".json")
            loadTranslationFile(langCode, moduleName, langPath)
        }
    }
    return nil
}
```

### Translate Function

```go
// Translate returns the translated text
// Fallback: module translation -> core translation -> original text
func Translate(lang, module, text string) string {
    // Try module-specific translation
    if module != "core" {
        if val := getTranslation(lang, module, text); val != "" {
            return val
        }
    }

    // Fallback to core module
    if val := getTranslation(lang, "core", text); val != "" {
        return val
    }

    // Return original text
    return text
}

// T is shorthand for Translate
func T(lang, module, text string) string {
    return Translate(lang, module, text)
}
```

## Template Integration

### Template Function

```go
// internal/system/template/funcs.go

func GetFuncMap(lang, module string) template.FuncMap {
    return template.FuncMap{
        "T": func(text string) string {
            return i18n.T(lang, module, text)
        },
    }
}
```

```html

    <p>{{T "Items found"}}: {{len .items}}</p>
```

## Language Selection

### From Request

```go
// Middleware to set language
func LanguageMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // Priority: query param > cookie > header > default
        lang := c.Query("lang")
        if lang == "" {
            lang, _ = c.Cookie("lang")
        }
        if lang == "" {
            lang = c.GetHeader("Accept-Language")
            if len(lang) >= 2 {
                lang = lang[:2] // Take first 2 chars
            }
        }
        if lang == "" {
            lang = "en"
        }

        c.Set("lang", lang)
        c.Next()
    }
}
```

### Setting Language

```go
// Handler to change language
func SetLanguage(c *gin.Context) {
    lang := c.Param("lang")

    // Validate language exists
    available := i18n.GetAvailableLanguages()
    valid := false
    for _, l := range available {
        if l == lang {
            valid = true
            break
        }
    }

    if valid {
        c.SetCookie("lang", lang, 86400*365, "/", "", false, false)
    }

    // Redirect back
    referer := c.GetHeader("Referer")
    if referer == "" {
        referer = "/"
    }
    c.Redirect(http.StatusFound, referer)
}
```

## Available Languages

```go
// GetAvailableLanguages returns all loaded language codes
func GetAvailableLanguages() []string {
    langs := make([]string, 0, len(translations))
    for lang := range translations {
        langs = append(langs, lang)
    }
    return langs
}
```

## Adding a New Language

1. **Create translation file** in each module:

```bash
# For each module
touch modules/yourmodule/views/lang/fr.json
```

2. **Add translations**:

```json
{
    "_meta": {
        "language": "Français",
        "code": "fr"
    },
    "Welcome": "Bienvenue",
    "Items": "Articles"
}
```

3. **Restart application** to reload translations

## Translation Keys Best Practices

### Use English as Keys

```json
// Good - readable, self-documenting
{
    "Welcome to the dashboard": "Bienvenido al tablero",
    "Save changes": "Guardar cambios"
}

// Avoid - unclear meaning
{
    "msg_001": "Bienvenido al tablero",
    "btn_save": "Guardar cambios"
}
```

### Keep Keys Consistent

```json
// Core module - shared translations
{
    "Save": "Guardar",
    "Cancel": "Cancelar",
    "Delete": "Eliminar",
    "Edit": "Editar",
    "Loading...": "Cargando..."
}
```

### Context in Keys

```json
// When same word has different meanings
{
    "Save (button)": "Guardar",
    "Save (noun)": "Ahorro"
}
```

## Fallback Chain

1. **Module translation** - Check current module's translations
2. **Core translation** - Check core module's translations
3. **Original text** - Return the key itself

```go
// Example: Looking for "Save" in tasks module with lang=es

// 1. Check: translations["es"]["tasks"]["Save"]
//    Not found

// 2. Check: translations["es"]["core"]["Save"]
//    Found: "Guardar"

// 3. Return: "Guardar"
```

## Pluralization

Handle plurals in handlers:

```go
func getItemCountText(lang, module string, count int) string {
    if count == 0 {
        return i18n.T(lang, module, "No items")
    } else if count == 1 {
        return i18n.T(lang, module, "1 item")
    }
    return fmt.Sprintf(i18n.T(lang, module, "%d items"), count)
}
```

```json
// en.json
{
    "No items": "No items",
    "1 item": "1 item",
    "%d items": "%d items"
}

// es.json
{
    "No items": "Sin artículos",
    "1 item": "1 artículo",
    "%d items": "%d artículos"
}
```

## Module-Specific Translations

Each module maintains its own translations:

```
modules/
├── core/
│   └── views/lang/
│       ├── en.json  # Common: Save, Cancel, Login, etc.
│       └── es.json
├── tasks/
│   └── views/lang/
│       ├── en.json  # Task-specific: Due date, Priority, etc.
│       └── es.json
└── yourmodule/
    └── views/lang/
        ├── en.json  # Your module's translations
        └── es.json
```

## Debug Mode

Log missing translations during development:

```go
func Translate(lang, module, text string) string {
    // ... lookup logic ...

    // Log missing translation in debug mode
    if os.Getenv("DEBUG") == "true" {
        log.Printf("Missing translation: [%s][%s] %q", lang, module, text)
    }

    return text
}
```
