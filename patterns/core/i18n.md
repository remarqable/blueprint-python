## Overview

Simple, runtime-loaded translation system:
- JSON files in `app/lang/` directory
- Variable substitution with `{name}` placeholders
- Fallback chain: requested language → English → key itself
- RTL language detection for Arabic, Persian, Hebrew, Urdu

## JSON Catalog Format

### Structure

```
app/lang/
├── en.json    # English (required - fallback)
├── es.json    # Spanish
├── fr.json    # French
└── ar.json    # Arabic (RTL)
```

## i18n Module

```python
# app/platform/i18n.py
"""Internationalization with JSON catalogs."""

import json
from pathlib import Path
from typing import Dict, Optional, Any
from threading import RLock
from flask import Flask, request, g, session

# Thread-safe translation storage
_translations: Dict[str, Dict[str, str]] = {}
_lock = RLock()

# RTL languages
RTL_LANGUAGES = {'ar', 'fa', 'he', 'ur'}
DEFAULT_LANGUAGE = 'en'


def init_i18n(app: Flask) -> None:
    """Initialize i18n and preload translations."""
    lang_dir = Path(app.root_path) / 'lang'

    if lang_dir.exists():
        for lang_file in lang_dir.glob('*.json'):
            lang_code = lang_file.stem
            _load_language(lang_code, lang_file)

    @app.before_request
    def detect_language():
        g.lang = _detect_language()
        g.is_rtl = g.lang in RTL_LANGUAGES

    @app.context_processor
    def inject_i18n():
        return {
            't': t,
            'lang': get_lang(),
            'is_rtl': is_rtl(),
        }


def _load_language(lang_code: str, file_path: Path) -> None:
    """Load a language file into memory."""
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            data = json.load(f)
        with _lock:
            _translations[lang_code] = data
    except (json.JSONDecodeError, IOError) as e:
        print(f'Error loading {lang_code}: {e}')


def _detect_language() -> str:
    """Detect user's preferred language.

    Priority:
    1. Query parameter (?lang=es)
    2. Session value
    3. Accept-Language header
    4. Default language
    """
    # Query parameter
    lang = request.args.get('lang')
    if lang and lang in _translations:
        session['lang'] = lang
        return lang

    # Session
    lang = session.get('lang')
    if lang and lang in _translations:
        return lang

    # Accept-Language header
    for lang, _ in request.accept_languages:
        lang_code = lang.split('-')[0].lower()
        if lang_code in _translations:
            return lang_code

    return DEFAULT_LANGUAGE


def get_lang() -> str:
    """Get current language code."""
    from flask import has_request_context
    if has_request_context():
        return getattr(g, 'lang', DEFAULT_LANGUAGE)
    return DEFAULT_LANGUAGE


def is_rtl() -> bool:
    """Check if current language is RTL."""
    return get_lang() in RTL_LANGUAGES


def t(key: str, lang: Optional[str] = None, **kwargs: Any) -> str:
    """Translate a key.

    Args:
        key: Translation key (e.g., 'settings.theme_label')
        lang: Language code (default: current)
        **kwargs: Variables to substitute

    Returns:
        Translated string

    Examples:
        >>> t('auth.welcome_back', name='Alice')
        'Welcome back, Alice!'
    """
    if lang is None:
        lang = get_lang()

    # Try requested language
    text = _get_translation(lang, key)

    # Fallback to English
    if text is None and lang != 'en':
        text = _get_translation('en', key)

    # Fallback to key itself
    if text is None:
        return key

    # Variable substitution
    if kwargs:
        try:
            text = text.format(**kwargs)
        except KeyError:
            pass

    return text


def _get_translation(lang: str, key: str) -> Optional[str]:
    """Get translation for language and key."""
    with _lock:
        return _translations.get(lang, {}).get(key)


def available_languages() -> list:
    """Get list of available languages."""
    with _lock:
        return list(_translations.keys())
```

## Language Detection

### Priority Order

1. **Query parameter**: `?lang=es` (also saves to session)
2. **Session value**: Remembered from previous visit
3. **Accept-Language header**: Browser preference
4. **Default**: English

### Switching Languages

```html
<!-- Language selector -->
<div x-data="{ open: false }" class="relative">
  <button @click="open = !open" @keydown.escape="open = false"
          :aria-expanded="open" aria-haspopup="menu"
          class="btn-secondary">
    <span class="sr-only">{{ _('nav.change_language') }}</span>
    {{ lang|upper }}
  </button>

  <ul x-show="open" @click.outside="open = false" x-cloak x-transition role="menu"
      class="absolute end-0 mt-2 w-40 rounded-md bg-white py-1 shadow-lg
             ring-1 ring-black/5 dark:bg-slate-800">
    {% for code, label in AVAILABLE_LANGUAGES.items() %}
    <li>
      <a href="?lang={{ code }}" role="menuitem" lang="{{ code }}"
         class="block px-4 py-2 text-sm hover:bg-slate-50 dark:hover:bg-slate-700
                {{ 'font-semibold' if code == lang }}"
         {{ 'aria-current="true"' if code == lang }}>{{ label }}</a>
    </li>
    {% endfor %}
  </ul>
</div>
```

## Available Languages

Expose the catalogue to templates rather than hardcoding a list in markup:

```python
# app/platform/i18n.py
AVAILABLE_LANGUAGES = {
    'en': 'English',
    'es': 'Español',
    'fr': 'Français',
    'ar': 'العربية',
}

RTL_LANGUAGES = {'ar', 'he', 'fa', 'ur'}


def init_i18n(app):
    @app.context_processor
    def inject_i18n():
        return {
            'lang': g.lang,
            'is_rtl': g.lang in RTL_LANGUAGES,
            'AVAILABLE_LANGUAGES': AVAILABLE_LANGUAGES,
        }
```

Each option carries its own `lang` attribute so a screen reader pronounces
"Español" in Spanish rather than in the page language.


```html
<html lang="{{ lang }}" dir="{{ 'rtl' if is_rtl else 'ltr' }}">
```

### In Controllers

```python
from app.platform.i18n import t

@bp.route('/settings', methods=['POST'])
def update_setting():
    # ... update logic
    flash(t('settings.saved'), 'success')
    return redirect(url_for('settings.index'))
```

## RTL Support

### Automatic Detection

RTL is automatically detected for: Arabic (ar), Persian (fa), Hebrew (he), Urdu (ur)

### CSS Adjustments

Bootstrap 5 handles most RTL automatically. For custom styles:

```css
/* app/static/css/app.css */
[dir="rtl"] .me-3 {
  margin-left: 1rem !important;
  margin-right: 0 !important;
}
```

### Template Pattern

```html
<!DOCTYPE html>
<html lang="{{ lang }}" dir="{{ 'rtl' if is_rtl else 'ltr' }}">
<head>
  <!-- One stylesheet for both directions. Tailwind's logical properties
       (ms-/me-, ps-/pe-, text-start/end) flip with the dir attribute, so
       there is no RTL build and no [dir="rtl"] override block. -->
  <link href="{{ url_for('static', filename='css/app.css') }}" rel="stylesheet">
</head>
```

> Writing `ml-4` instead of `ms-4` is the one way to break RTL in this stack, and
> it will not show up until someone loads the Arabic locale. See
> [frontend.md § RTL Support](frontend.md#rtl-support).

## Best Practices

### Keys

✅ **Do:**
- Use dot notation: `feature.action.element`
- Keep keys descriptive but concise
- Group related keys together
- Always provide English fallback

❌ **Don't:**
- Don't use hardcoded strings in templates
- Don't embed HTML in translations (use separate keys)
- Don't include numbers/values in keys

### Translations

✅ **Do:**
- Use `{name}` placeholders for dynamic content
- Keep translations natural for each language
- Test RTL languages early

❌ **Don't:**
- Don't concatenate translated strings
- Don't assume word order is same across languages

### Adding New Keys

1. Add to `en.json` first
2. Add to other language files
3. Use `t('key')` in template
4. Test all languages
